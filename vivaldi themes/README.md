# Matching Vivaldi Browser Themes

Each `.zip` package in this folder is a native Vivaldi browser theme tuned to match its corresponding **VBerry** extension theme (matching canvas, recessed window rail, ink foreground, highlight accent, and `8px` corner rounding so Vivaldi's toolbar and sidebar blend seamlessly into VBerry's Side Panel).

## How to Install in Vivaldi

1. Open **Vivaldi Settings → Themes** (`vivaldi://settings/themes/`).
2. Click **Open Theme…** underneath the theme library.
3. Select one (or more) `.zip` files from this `vivaldi themes` folder.
4. In **VBerry Preferences → Appearance & tabs**, select the matching theme (or set Vivaldi's **Theme Schedule** alongside VBerry's **System** mode to pair *Mineral Slate* by day and *Graphite Plum* by night).
5. If you customize a theme's colors in **VBerry Preferences → Appearance & tabs → Customize colors**, you can paste the hex codes directly into Vivaldi's **Themes → Editor → Colors** fields so both match.
